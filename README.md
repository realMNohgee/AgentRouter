# AgentRouter 🧭 — intelligent task routing for multi-agent systems
![CI](https://github.com/realMNohgee/agentrouter/actions/workflows/ci.yml/badge.svg) ![Python](https://img.shields.io/badge/python-3.9%2B-blue.svg) ![License](https://img.shields.io/badge/license-MIT-blue.svg)

Classify tasks and route to the right agent by capability, cost, and trust.

```bash
python3 agentrouter.py --task "Find AI safety papers" --agents agents.json
```
